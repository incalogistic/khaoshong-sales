# KHAOSHONG Sales — แอปพนักงานขาย

แอปบนมือถือสำหรับ **แวนเซลล์** และ **พรีเซลล์** ของ หจก. อินคา โลจิสติก
ข้อมูลทั้งหมดอ่าน/บันทึกที่ระบบ **DMS** (Google Apps Script) โดยตรง — ไม่มีฐานข้อมูลแยก

## ใช้งานได้
| แวนเซลล์ | พรีเซลล์ |
|---|---|
| ขายสินค้า + เช็กส่วนลด Tier ทันที (ลัง/กล่อง/ชิ้น ดีดหน่วยอัตโนมัติ) | สั่งขาย (ใบสั่งขาย SO) + เช็กส่วนลด Tier |
| พิมพ์บิลผ่าน RawBT (ต้นฉบับ/สำเนา จำกัดจำนวนพิมพ์ซ้ำตามแอดมิน) | ลูกค้าที่ดูแล: ยอดค้างชำระ / ออเดอร์เดือนนี้ |
| รับชำระ เงินสด / QR (แนบสลิป) — ต้องรับชำระก่อนขายร้านถัดไป | เปิดร้านใหม่: จังหวัด/อำเภอ/ตำบล, เลขภาษี, GPS, รูปหน้าร้าน |
| บิลวันนี้, สรุปยอดวันนี้ (พิมพ์ได้) | ออเดอร์เดือนนี้ + สถานะ (ยกเลิกได้ที่แอดมินเท่านั้น) |
| สต็อกบนรถ (พิมพ์ได้), ขอโหลด / ขอคืนสินค้า | |

เข้าระบบด้วย **User + PIN 6 หลัก** (ถาม PIN ทุกครั้งที่เปิดแอป) — ใช้ได้เฉพาะตำแหน่งที่ System Support เปิดช่องทาง "แอป"

## ติดตั้ง (ทำครั้งเดียว)
1. อัปเดต DMS เป็นเวอร์ชัน **1.5.0** ขึ้นไป (มี `doPost` สำหรับแอป) และ Deploy ให้ "Who has access" = **Anyone**
2. เปิด GitHub Pages: Settings → Pages → Source = *Deploy from a branch* → Branch = `main` / `(root)` → Save
3. ลิงก์แอปคือ `https://incalogistic.github.io/khaoshong-sales/`
4. เปิดลิงก์ในมือถือ (Chrome) → ใส่ลิงก์ Web App ของ DMS (ลงท้าย `/exec`) → เข้าระบบ
   หรือใส่ลิงก์ไว้ใน `config.js` ครั้งเดียว ทุกเครื่องจะไม่ต้องกรอก
5. เมนู Chrome ⋮ → **เพิ่มลงในหน้าจอหลัก** เพื่อใช้เหมือนแอป

## เครื่องพิมพ์บิล
- แนะนำ Xprinter XP-P300 (บลูทูธ 80 มม.) + แอป **RawBT** (Android)
- กด "พิมพ์ผ่าน RawBT" → แอปสร้างรูปใบเสร็จ → เลือกแชร์ไป RawBT → พิมพ์
- ความกว้างกระดาษ 58/80 มม. ตั้งที่ DMS: ตั้งค่าระบบ → รถแวน

## โครงสร้างไฟล์
- `index.html`, `css/app.css`, `js/app.js` — ตัวแอป (ไม่มีไลบรารีภายนอก)
- `config.js` — ลิงก์ DMS
- `manifest.webmanifest`, `sw.js`, `icons/` — ติดตั้งลงหน้าจอหลัก
